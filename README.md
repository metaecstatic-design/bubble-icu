# Bubble ICU

Bubble ICU is a synthetic ICU workspace prototype for exploring bedside documentation and clinical workflows. It uses fictional records and is intended for demonstration.

## Run the prototype

Open `index.html` in a modern browser. No server or installation is required.

Run `npm test` with Node.js 20 or later to check the browser script and bundled demo records. The command needs no third-party packages.

## Develop with coding agents

Use a GitHub issue to describe one change and its acceptance criteria. Follow [AGENTS.md](AGENTS.md). Keep the change on an issue-specific branch, run the checks, and open a draft pull request for a maintainer to try and review. The pull request should describe what changed and how to verify it. Review and merging are maintainer decisions.

See [ROADMAP.md](ROADMAP.md) for the current development queue. Use only fictional examples in issues, tests and screenshots.
